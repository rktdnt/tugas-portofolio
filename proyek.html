Web Platform 2026 - Sekarang

Sistem Manajemen Event HIMTI

Dirancang untuk mengatasi inefisiensi pencatatan manual pada kepengurusan himpunan mahasiswa.

Fitur Kunci:
  • Autentikasi role-based (Admin, Panitia, dan Peserta).
  • Penerbitan e-tiket dengan QR Code verifikasi.
  • Integrasi basis data serverless Neon PostgreSQL via Prisma ORM.
Kunjungi Repositori GitHub
AOSP Project 2025 - Sekarang

Halcyon Project OS

Sistem operasi berbasis Android murni yang difokuskan pada efisiensi baterai dan kebebasan personalisasi.

Fitur Kunci:
  • Kustomisasi framework dan patch performa kernel.
  • UI minimalis berorientasi Material You tanpa bloatware.
  • Dukungan continuous integration (CI) build otomatis.
